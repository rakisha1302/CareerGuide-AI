# CareerGuide AI 🚀

### AI-Powered Career Guidance and Placement Readiness Platform

CareerGuide AI is an intelligent career guidance platform designed to help students identify suitable career paths, analyze skill gaps, and prepare for placement opportunities using AI-powered recommendations.

## 🌟 Key Features

- **User Authentication:** Registration and login for students.
- **Career Recommendations:** Discover suitable career paths based on your skills.
- **Skill Gap Analysis:** Identify missing skills for your target career.
- **Career Digital Twin:** Maintain your career profile, interests, skills, and projects.
- **AI Mock Interviews:** Practice interview questions and receive AI-powered feedback.
- **Interview History:** Review previous interview performance.

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Groq AI
- Scikit-learn
- Pandas
- Python-dotenv

## ⚙️ Installation and Setup

1. Clone the repository:

   `git clone https://github.com/rakisha1302/CareerGuide-AI.git`

2. Open the project folder:

   `cd CareerGuide-AI`

3. Create a virtual environment:

   `python -m venv .venv`

4. Activate the environment:

   ` .venv\Scripts\activate `

5. Install dependencies:

   `pip install -r requirements.txt`

6. Create a `.env` file and add your Groq API key:

   `GROQ_API_KEY=your_api_key_here`

7. Run the application:

   `streamlit run app.py`
